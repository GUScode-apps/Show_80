# SHOW DE LOS 80

Página web sencilla para registro de participantes en un Show de talento.

## STACK

- Web desarrollada con html y css.
- Formulario de registro con Google Sheets F>ormulario.
- Base de datos en hoja Google Sheets.
- Despliegue en GitHub como site.

## SECCIONES DE LA PÁGINA

- Hero page.
- Sección de breve información con video incluido.
- Formukario -> Botón para ir a link de formulario google.
- Footer informativo del evento.
